# Articles

Chaque fichier Markdown (`.md`) de ce dossier est publié automatiquement dans la
section **Articles** du portfolio dès qu'il est poussé sur la branche `main` de GitHub
(aucune reconstruction manuelle n'est nécessaire, le site se synchronise en quelques minutes).

Nommez le fichier `AAAA-MM-JJ-titre-court.md` et commencez-le par un en-tête :

```markdown
---
title: Titre de l'article
date: 2026-10-24
summary: Une ou deux phrases affichées sur la carte de l'article.
tags: [Data Science, Python]
---

Contenu de l'article en Markdown…
```

Ce fichier `README.md` n'est pas publié.
